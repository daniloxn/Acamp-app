# Produto e escopo

## Confirmado

- O aplicativo se chama **ACAMP** e será feito com **Tauri 2**.
- Seu objetivo é auxiliar alunos nos estudos a partir de assuntos que desejam aprender.
- A primeira versão usa `agy` ou `gemini` via CLI para conversar e gerar conteúdo de estudo.
- O aluno entra por uma lista de assuntos; cada assunto mantém conversa e contexto de aprendizagem próprios.

## Funcionalidades desejadas

- Conversa para tirar dúvidas.
- Quiz, testes, provas e planos de estudo.
- Prompts padronizados para cada etapa do aplicativo.
- Uso de vídeos do YouTube como fonte de conteúdo, além de perguntas e assuntos informados pelo aluno.

Essas funcionalidades desejadas ainda não estão todas implementadas. Consulte [o estado do aplicativo](aplicativo.md).
